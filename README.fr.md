# CRONOSALA

[English](README.md) · [Română](README.ro.md) · **Français** · [Italiano](README.it.md) · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · [Magyar](README.hu.md)

Des minuteurs et un journal d’entraînement pour la salle de sport, dans un seul fichier HTML hors ligne, sans suivi.

**[Ouvrir l’application →](https://cronosala.chiuta.ro/)**

_Version : 3.2.3 · Dernière mise à jour : 2026-11-20_

## Fonctionnalités

- Minuteurs de séries et de repos avec pause adaptative qui apprend de vos ajustements de ±15 s.
- Journal kg × répétitions pour chaque série, avec records personnels, statistiques et double progression.
- Programme mensuel de quatre semaines (la 4e = décharge), alternatives « machine occupée », échauffement et retour au calme guidés.
- Export et import de toutes les données ; rien ne quitte le navigateur.

## Utilisation

Ouvrez la page en ligne, ou téléchargez `index.html` et ouvrez-le dans un navigateur récent. Aucune installation, aucun build.

## Limites

- L’interface existe en 8 langues (roumain, anglais, français, allemand, espagnol, italien, hongrois, portugais) ; le choix se trouve en bas de l’écran d’accueil. Les annonces vocales suivent la langue choisie si l’appareil dispose d’une voix correspondante.
- Les données restent par appareil et navigateur ; utilisez l’export pour les déplacer. Ce n’est ni un avis médical ni une prescription d’entraînement.

## Confidentialité

Tout reste dans votre navigateur (localStorage / IndexedDB) ; pas de compte, pas de suivi. Aucune requête réseau.
