# CRONOSALA

[English](README.md) · [Română](README.ro.md) · [Français](README.fr.md) · **Italiano** · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · [Magyar](README.hu.md)

Timer e diario di allenamento per la palestra, in un solo file HTML offline, senza tracciamento.

**[Apri l’app →](https://cronosala.chiuta.ro/)**

_Versione: 3.0.0 · Ultimo aggiornamento: 2026-11-06_

## Funzioni

- Timer per serie e recuperi con pausa adattiva che impara dai tuoi aggiustamenti di ±15 s.
- Diario kg × ripetizioni per ogni serie, con record personali, statistiche e doppia progressione.
- Programma mensile di quattro settimane (la 4ª = scarico), alternative «macchina occupata», riscaldamento e defaticamento guidati.
- Esportazione e importazione di tutti i dati; nulla lascia il browser.

## Utilizzo

Apri la pagina online, oppure scarica `index.html` e aprilo in un browser recente. Nessuna installazione, nessuna build.

## Limiti

- Per ora l’interfaccia è solo in rumeno.
- I dati restano per dispositivo e browser; usa l’esportazione per spostarli. Non è un parere medico né una prescrizione di allenamento.

## Privacy

Tutto resta nel tuo browser (localStorage / IndexedDB); nessun account, nessun tracciamento. Nessuna richiesta di rete.
