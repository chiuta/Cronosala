# CRONOSALA

[English](README.md) · [Română](README.ro.md) · [Français](README.fr.md) · [Italiano](README.it.md) · [Español](README.es.md) · [Português](README.pt.md) · [Deutsch](README.de.md) · **Magyar**

Időzítők és edzésnapló az edzőterembe, egyetlen offline HTML-fájlban, követés nélkül.

**[Az alkalmazás megnyitása →](https://cronosala.chiuta.ro/)**

_Verzió: 3.0.0 · Utolsó frissítés: 2026-11-06_

## Funkciók

- Széria- és pihenőidő-időzítők adaptív szünettel, amely tanul a ±15 mp-es módosításaidból.
- kg × ismétlés napló minden szériához, egyéni rekordokkal, statisztikákkal és dupla progresszióval.
- Négyhetes havi program (a 4. hét = tehermentesítő), „foglalt gép” alternatívák, vezetett bemelegítés és levezetés.
- Az összes adat exportja és importja; semmi sem hagyja el a böngészőt.

## Használat

Nyisd meg az oldalt online, vagy töltsd le az `index.html` fájlt, és nyisd meg egy friss böngészőben. Nincs telepítés, nincs build.

## Korlátok

- A felület egyelőre csak románul érhető el.
- Az adatok eszközönként és böngészőnként tárolódnak; az exporttal vihetők át. Nem orvosi tanács és nem edzésterv-előírás.

## Adatvédelem

Minden a böngésződben marad (localStorage / IndexedDB); nincs fiók, nincs követés. Nincsenek hálózati kérések.
